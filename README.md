# Kapibara AI — сайт-портфолио

Первая рабочая версия сайта Kapibara AI: дизайн, афиши, рекламные баннеры, обложки и простые сайты-визитки.

## Структура
- `index.html` — главная страница, шесть кликабельных плиток и контакты.
- `portfolio.html` — категории портфолио (пока честные заглушки).
- `assets/style.css` — адаптивный дизайн и анимации персонажа.
- `assets/app.js` — переключаемый курсор-капибара для компьютеров.
- `assets/kapibara-logo.webp` — веб-версия утверждённого логотипа без изменения художественного оформления.
- `assets/kapibara-cursor.webp` — малая версия персонажа для курсора.

## Как опубликовать на GitHub Pages
Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

Постепенно наполняем портфолио. Контакт для связи: https://t.me/KapibaraAI
